# ── flash-attn 2.8.3 on Bridges-2 (glibc 2.28) ────────────────────────────
# Prebuilt wheels require glibc>=2.32 and will NOT load. It must be built
# from source, and the resulting .so references __libc_single_threaded
# (GLIBC_2.32, emitted by the Anaconda toolchain) which glibc 2.28 lacks.
# Fix applied (already done in the urL venv):
#   1. build from source:  MAX_JOBS=4 pip install flash-attn==2.8.3 \
#          --no-build-isolation --no-cache-dir --no-binary flash-attn
#   2. patchelf --clear-symbol-version __libc_single_threaded <flash_attn_2_cuda.so>
#   3. rewrite its Verneed GLIBC_2.32 entry -> GLIBC_2.14
#   4. compile a tiny shim: `char __libc_single_threaded = 0;` -> libsinglethreaded_shim.so
#      place next to the .so and: patchelf --add-needed libsinglethreaded_shim.so \
#          --add-rpath '$ORIGIN' <flash_attn_2_cuda.so>
